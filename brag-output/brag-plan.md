# Brag Plan: loopsmith

## What is this app?
loopsmith runs self-evolving agent loops from a plain-text config: AI does the work, compiled code checks the files, and the run stops only when the gate passes — the model never gets to say "done."

## The angle
Treat the user's tone line as a skill-craft manifesto, not a joke. This is a forge-colored product film about **purpose-specific skills that evolve into loops**, with the deterministic gate as the punchline.

## Hook (first 2-3 seconds)
Full-screen ember tagline, verbatim from the site header:
**The skill to create self evolving loops based purpose specific skills**

## Key moments (the middle)
- Hero headline from the landing page: **Describe a job once. It runs until it is actually done.**
- A terminal-style loop panel: config file → `check gate` → **PASS** (quench cyan) vs model saying "done" crossed out
- Three forge cards, one by one: **The gate is compiled code** · **The model never gets to say "done"** · **Runs until it actually passes**

## Outro / punchline
loopsmith mark + wordmark on warm ground; hold on **loopsmith**.

## User flow worth showing
Entry: write loop config (YAML/Markdown) → key action: agent iterates while deterministic checker reads files → result: **PASS** and loop stops (or revoke if artifacts disappear). Recreated as a terminal mock, not the marketing page alone.

## Tone
- Preset: `app-store`
- Creative direction: **The skill to create self evolving loop based purpose specific skills** (user-provided)
- Interpretation: Earnest, feature-forward, forge palette; voice narration carries the skill thesis while visuals show real product copy and the gate loop.

## Format: landscape — 1920x1080
## Duration: 20 seconds

- Body font: same system stack

## Share copy (draft)
Self-evolving loops from purpose-specific skills — describe the job once, and loopsmith runs until compiled code says it's actually done (the model never gets to say "done").

## Audio direction
- Role: warm upbeat bed with sparse professional SFX
- Music: `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3`, low start, duck under voice
- Music treatment: fade in 0.3s, hold ~0.32 gain, duck to ~0.14 during VO, return for outro; fade out last 0.8s
- Music cue guidance: bundled preset ~120 BPM; beat-lock hero at ~3.02s strong cue; card sequence on beats ~12.65–13.7s (every other beat for readable text)
- Audio-reactive treatment: subtle; ember glow and card borders breathe with bass/RMS — no waveform UI
- SFX posture: sparse — click on PASS, soft impact on hero, select ticks on cards
- Audio-coupled moments: VO drives pacing; PASS click; sequential card reveals
- Restraint rule: music supports, never fights narration

## Voiceover script
Self-evolving loops, built from purpose-specific skills. Describe a job once in plain text. loopsmith puts the AI to work, checks the actual files with code you wrote, and sends it back until it passes. The model never gets to say done. That's loopsmith.
